The idea

One place for
parallel work.

Meringue puts a chat, an AgentTree, and structured logs over the coding agents you already use. Projects, issues, workers, and questions stay visible while work happens in its own space.

It coordinates the work around your agent, not instead of it.

Bring your own coding agent

Keep the agent
you already trust.

Meringue is harness agnostic by design. Use Pi, Claude Code, or Codex CLI. Meringue handles orchestration, state, logs, and navigation while your chosen agent does the coding.

New backends can fit behind the same small integration layer. Your workflow does not have to wait for one vendor.

Get started

One command
to begin.

Install from a terminal, then run meringue inside a repository. Bring a signed in Pi, Claude Code, or Codex CLI.

INSTALL AND RUN
