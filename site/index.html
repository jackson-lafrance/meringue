The idea

One place for
parallel work.

Meringue puts a chat, an agent tree, and structured logs over the coding agents you already use. Projects, issues, workers, and questions stay visible while work happens in its own space.

It coordinates the work around your agent—not instead of it.

Why Meringue

Useful structure.
No new ritual.

›

One clear view

Send a goal in plain English, then watch the head, issue, and worker progress without a wall of tabs.

⌘

Safe parallelism

Every worker gets its own git worktree and branch. Parallel work stays parallel and your checkout stays safe.

↗

Follow the signal

Structured lifecycle logs keep important updates readable, so you can jump in when a decision needs you.

+

Easy to extend

Readable state and small provider boundaries make the system inspectable, replaceable, and yours.

Bring your own coding agent

Keep the agent
you already trust.

Meringue is harness agnostic by design. Use Pi, Claude Code, or Codex CLI—Meringue handles orchestration, state, logs, and navigation while your chosen agent does the coding.

New backends can fit behind the same small integration layer. Your workflow does not have to wait for one vendor.

Get started

One command
to begin.

Install from a terminal, then run meringue inside a repository. Bring a signed-in Pi, Claude Code, or Codex CLI.

INSTALL AND RUN 
curl -fsSL https://raw.githubusercontent.com/jackson-lafrance/meringue/main/install.sh | sh
